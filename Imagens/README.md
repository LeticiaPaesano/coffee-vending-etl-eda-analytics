# 📊 Gráficos da análise de vendas de café

Esta pasta reúne os gráficos exportados em formato PNG durante a análise exploratória dos dados de vendas da máquina automática de café.

## Arquivos

- **Distribuicao Horaria de Vendas.png** — distribuição das transações por horário.
- **Metodos de Pagamento.png** — participação dos métodos de pagamento.
- **Mix de Produtos (Analise ABC).png** — classificação dos produtos pela participação na receita.
- **Performance Mensal.png** — evolução mensal das vendas.
- **Performance Semanal.png** — comparação das vendas por dia da semana.
- **Receita por Periodo.png** — receita por período do dia.
- **Vendas por periodo.png** — volume de vendas por período do dia.

Os arquivos são imagens estáticas de apoio à documentação. O dashboard interativo está na pasta [cafe-dashboard](../cafe-dashboard/).
